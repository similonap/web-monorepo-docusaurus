# Y-Clone (Login) (twitter)

Download het [starterproject](/exercise-files/nextjs/labo-4-y-clone-login-twitter/starter.zip) en voer daarna `npm install` uit.

Wanneer je klaar bent, kan je jouw uitwerking vergelijken met de [voorbeeldoplossing](/exercise-files/nextjs/labo-4-y-clone-login-twitter/solution.zip).

> 📂 **Naam project:** `lab-nextjs-y-forms`  
> 🔗 **Basisproject:** de vereiste begincode is inbegrepen in het [starterproject](/exercise-files/nextjs/labo-4-y-clone-login-twitter/starter.zip).

Breid de y-clone oefening uit met een login systeem. Als je een post maakt moet het onder de gebruikersnaam gebeuren die je opgeeft bij het inloggen.
