## Line 1 — Hook (Frame 1)

    In React Native schrijf je geen CSS. Je styling is gewoon JavaScript: een object met properties in camelCase, zoals background color en border radius.

## Line 2 — StyleSheet.create (Frame 2)

    Met style sheet punt create maak je één object met al je stijlen. Elke key is een stijl met een naam, zoals container of box.

## Line 3 — De style prop (Frame 3)

    Die stijl geef je mee aan de style prop van een component. Getallen schrijf je zonder eenheid, dus geen p x achter een width of een height.

## Line 4 — Rand en hoeken (Frame 4)

    Border width bepaalt hoe dik de rand is, border color de kleur van de rand, en border radius hoe sterk de hoeken afgerond worden.

## Line 5 — De statusbalk (Frame 5)

    Bovenaan het scherm staat de statusbalk. Constants punt status bar height is de hoogte ervan. Met die padding bovenaan komt je app er niet onder te staan.

## Line 6 — Inline styles (Frame 6)

    Je kan ook rechtstreeks een object meegeven: een inline style. Handig om snel iets te testen, maar met een style sheet blijft je JSX leesbaar en hergebruik je je stijlen.
