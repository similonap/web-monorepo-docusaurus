## Video direction (TS light restyle)

This film is being RESTYLED (again). The previous attempt used the AP Hogeschool house style (white + AP red blocks, League Gothic, AP logo, red triangle shards, charcoal code). That style is REJECTED: remove all of it. The new look is **TS light**: a subtle, calm white style with TypeScript-blue accents that fits the course website. Voice-over, word timings, story beats and code content do NOT change; every reveal keeps its cue time. Source of truth: `frame.md`. Reference frame once it exists: `compositions/frames/02-fetch.html` (restyled first; copy its CSS tokens, @font-face block and ts-* classes verbatim).

- **Remove completely:** the AP logo `<img>` (assets/brand/...), all triangle shards, the red kicker tag + dark-red bar, red statement blocks, League Gothic and Source Sans 3 @font-face rules (assets/fonts-ap/...), charcoal code panels, `ap-*` classes. No logos anywhere.
- **Ground:** white `#FFFFFF` (full-duration background clip layer). Optionally a very faint `#F8FAFC` band; keep it subtle.
- **Colour roles:** ink `#1E293B` for text, `#475569` secondary, `#94A3B8` muted; panels `#F1F5F9`, hairlines `#E2E8F0`. **One accent: TypeScript blue `#3178C6`** (dark `#235A97`, tint `#EAF2FB`). Where a frame had its "one accent moment" (AP red / coral), use blue. Exception: true error output (the error `<p>`, `ok: false`, the "this goes wrong" mark in problem frames: skipped `setLoading(false)`, the late `setPosts(…)`, block B in frame 11) uses `#D14343`, thin and sparing. Never both a red and a blue key moment at the same time.
- **Type:** Inter for everything that is not code (kicker, labels, statements, hero words, UI); JetBrains Mono for code and chips. Hero words: Inter 700, tight tracking (-0.035em), as written (e.g. `useFetch`, `custom hooks`), ~150–180px. Statements Inter 500/700. No uppercase display type except small labels/kickers.
- **Kicker:** top-left at (80, 84): a 28×4px blue bar, 14px gap, then Inter 600 22px uppercase tracking 0.14em in blue (`DE BASIS`). Reveal: bar grows from 0 width (0.35s), text fades/slides 8px (0.4s).
- **Code surface (light):** background `#F8FAFC`, 1px `#E2E8F0` border, radius 12, shadow at most `0 1px 2px rgba(15,23,42,0.06)`. Title bar `#F1F5F9` with bottom hairline, file name Inter 500 20px `#475569` after a 10px blue square (radius 2). Status bar `#F1F5F9`, JetBrains Mono 18px `#94A3B8`. Line numbers `#94A3B8`. Syntax: keywords `#235A97`, strings `#0F7B6C`, functions / component names / numbers / true / false `#9A5B13`, types `#3178C6`, punctuation & JSX brackets `#64748B`, fold `⋯` `#94A3B8`, text `#1E293B`. Highlight wash `rgba(49,120,198,0.12)`. Key mark = 2px blue box radius 6 (fix); wrong mark = 2px `#D14343` box radius 6 (problem). Keep the existing positions, sizes and line metrics.
- **`scherm` card:** white card, 1px hairline, radius 12, label `scherm` above it (Inter 600 20px uppercase tracking 0.12em `#64748B`). Rows Inter 24px ink with an 8px round blue dot. Button = blue filled, white Inter 600 22px `Vernieuwen`, radius 6. Spinner: 56px ring, 5px `#E2E8F0`, 90° blue arc, round caps. Error `<p>`: Inter 500 ink with a 4px `#D14343` left bar.
- **Mini panel:** light, like the code surface, title bar 40px.
- **Chips:** `#F1F5F9`, hairline, radius 8, JetBrains Mono 24px ink, optional key label Inter 600 18px uppercase `#94A3B8`. New/selected = `#EAF2FB` background + blue border. Unwanted = 2px `#D14343` border. Struck = line-through + 35%. Value swap unchanged.
- **Render-tag:** blue-tint pill, `#235A97` JetBrains Mono 20px, radius 999.
- **Underline accents:** 6px blue bar radius 3 wiping in from the left.
- **Diagrams:** panels `#F1F5F9` + hairline, lines 2px `#94A3B8`, small solid arrowheads, key element blue.
- **Cursor:** dark ink `#1E293B` fill with white outline, no shadow; click ripple blue at 20%.
- **Dimming:** use opacity on the element (on white this reads as lighter, fine).
- **Motion:** keep every cue time. Calm power3.out, small offsets, no bounce, holds still (spinner may rotate).
- **Layout:** kicker (80, 84); code surface left (x 80, ~1060 wide, top ~170); right column x ≈ 1236–1840; nothing important below y ≈ 900.
- **Negative list:** no logos, no shards/decorative shapes, no coloured blocks behind big text, no AP red, no cream/coral, no serif or condensed fonts, no dark code surfaces, no gradients/glow, no em-dashes in visible text, no Math.random / Date.now.
