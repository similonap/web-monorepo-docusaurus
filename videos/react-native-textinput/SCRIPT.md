## Line 1 — Hook (Frame 1)

    Wil je dat de gebruiker iets intypt, dan gebruik je een text input. Dat is het invoerveld van React Native, zoals een input element op het web.

## Line 2 — Placeholder en rand (Frame 2)

    Met placeholder toon je een hint zolang het veld leeg is. Let op: een text input heeft standaard geen rand, die geef je zelf met border width.

## Line 3 — Toetsenbord en wachtwoord (Frame 3)

    Keyboard type kiest welk toetsenbord er verschijnt, bijvoorbeeld enkel cijfers. Secure text entry verbergt wat je typt, handig voor een wachtwoord.

## Line 4 — onChangeText (Frame 4)

    Om te weten wat er getypt wordt, gebruik je on change text. Die functie krijgt bij elke toets de nieuwe tekst mee. Bewaar je die in state, dan kan je ze meteen tonen.

## Line 5 — Meer events (Frame 5)

    On submit editing wordt opgeroepen als de gebruiker op enter of gereed drukt. On focus komt zodra het veld geselecteerd wordt.

## Line 6 — Samenvatting (Frame 6)

    Zo is een text input de basis van elk formulier: een zoekveld, een login of een chatbericht.
