## Line 1 — Hook (Frame 1)

    Klaar om je eerste React Native app te maken? In dit filmpje zet je alles klaar. Je installeert Node js en Expo Go, je maakt een nieuwe app aan en je opent ze op je eigen telefoon.

## Line 2 — Node.js downloaden (Frame 2)

    Op je computer heb je enkel Node js nodig. Ga naar de website van Node js en download de LTS versie. Die installeer je zoals elk ander programma.

## Line 3 — Node.js controleren (Frame 3)

    Open daarna een terminal en typ node min min version. Zie je een versienummer, dan is de installatie gelukt. Expo zelf hoef je niet te installeren: dat voer je telkens uit met N P X.

## Line 4 — Expo Go in Google Play (Frame 4)

    Dan je telefoon. Op een Android toestel open je de Google Play Store en zoek je naar Expo Go. Tik op installeren. De app is gratis.

## Line 5 — App Store (Frame 5)

    Heb je een iPhone of een iPad, dan vind je dezelfde app in de App Store.

## Line 6 — Nieuwe app aanmaken (Frame 6)

    Terug naar je computer. Een nieuwe app maak je aan met N P X create expo app at latest, gevolgd door de naam van je project. Hier noemen we het mijn app.

## Line 7 — SDK kiezen (Frame 7)

    Eerst vraagt Expo welke SDK versie je wil. Kies in deze cursus altijd Latest. Daarna installeert Expo alle packages. Dat duurt even, tot je ziet: your project is ready.

## Line 8 — Voorbeeldcode opruimen (Frame 8)

    Ga met C D naar de map van je project, en ruim de voorbeeldcode op met N P M run reset project. Op de vraag of je de bestanden wil bewaren, antwoord je met N.

## Line 9 — De app starten (Frame 9)

    Nu start je de app met N P X expo start. Dat start Metro, de bundler die je code klaarmaakt voor je telefoon. In de terminal verschijnt een QR code.

## Line 10 — QR code scannen (Frame 10)

    Open Expo Go op je telefoon en tik op scan QR code. Richt je camera op de QR code in de terminal. Op een iPhone scan je de code gewoon met de camera app.

## Line 11 — Hetzelfde netwerk (Frame 11)

    Let op: je computer en je telefoon moeten op hetzelfde netwerk zitten. Lukt het niet, bijvoorbeeld op het schoolnetwerk, start dan met N P X expo start min min tunnel.

## Line 12 — Bundelen en openen (Frame 12)

    Metro bundelt nu je code en stuurt ze naar je telefoon. In de terminal verschijnt bundled, en even later draait je app.

## Line 13 — Eerste wijziging (Frame 13)

    Pas nu de tekst aan in index punt t s x en sla het bestand op. Je hoeft niets opnieuw te starten: je telefoon toont meteen Hello World.

## Line 14 — Herladen op je telefoon (Frame 14)

    Loopt je app vast, of wil je ze helemaal opnieuw laden? Tik dan op het blauwe tandwiel in je app, of schud met je telefoon. Het ontwikkelmenu gaat open, en daar tik je op reload.

## Line 15 — Herladen vanaf je computer (Frame 15)

    Het kan ook vanaf je computer. Druk op R in de terminal waar N P X expo start draait, en je app laadt opnieuw.

## Line 16 — Samenvatting (Frame 16)

    Samengevat: Node js op je computer en Expo Go op je telefoon. Je maakt een app met create expo app, je start ze met N P X expo start en je scant de QR code. Veel plezier met je eerste app!
