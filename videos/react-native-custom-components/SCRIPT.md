## Line 1 — Hook (Frame 1)

    Net zoals in React maak je in React Native je eigen componenten. Zo splits je je app op in kleine stukjes die je kan hergebruiken.

## Line 2 — Props (Frame 2)

    Met props geef je informatie door aan een component. Box krijgt een kleur en een grootte, en die beschrijf je in de interface Box Props.

## Line 3 — Styles als prop (Frame 3)

    Je kan zelfs een volledig style object meegeven. Het type is Style Prop van View Style, en Box zet het gewoon op zijn View.

## Line 4 — Default styles (Frame 4)

    Maak je de prop optioneel met een vraagteken, dan kan je hem een standaardwaarde geven. Zonder props krijgt elke Box die standaard style.

## Line 5 — Style array (Frame 5)

    Iets wat enkel in React Native kan, is een array van styles. De standaard style staat eerst, en de style uit de prop komt erna.

## Line 6 — De laatste wint (Frame 6)

    De laatste style in de array heeft voorrang. Geef je enkel een andere achtergrondkleur mee, dan blijven de breedte en de hoogte gewoon behouden.
