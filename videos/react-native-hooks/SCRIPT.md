## Line 1 — Hook (Frame 1)

    Alle hooks uit React werken ook in React Native. Daarnaast heeft React Native een paar eigen hooks, met informatie over het toestel.

## Line 2 — useWindowDimensions (Frame 2)

    Use window dimensions geeft de afmetingen van het venster terug: de breedte, de hoogte, de pixeldichtheid en de tekstgrootte die de gebruiker koos.

## Line 3 — Responsive layout (Frame 3)

    Draai je de telefoon, dan rendert je component opnieuw, net zoals bij use state. Is het scherm breder dan zeshonderd, dan zet je de kleuren naast elkaar.

## Line 4 — Rekenen met de breedte (Frame 4)

    Je kan ook rekenen met de breedte. Het aantal kolommen hangt af van het scherm, en een tegel is de breedte gedeeld door het aantal kolommen.

## Line 5 — useColorScheme (Frame 5)

    Use color scheme vertelt of de gebruiker light of dark mode gekozen heeft. Verandert die instelling, dan rendert je component meteen opnieuw.

## Line 6 — Een thema (Frame 6)

    Handiger is een thema, met de kleuren voor beide modi op één plaats. Je component kiest het juiste thema en gebruikt de kleuren daaruit.
