## Line 1 — Hook (Frame 1)

    In React Native bestaan er geen HTML elementen. Geen div, geen p en geen button. In de plaats gebruik je core components. De belangrijkste is de View.

## Line 2 — Een container (Frame 2)

    Een View is een container. Hij groepeert andere componenten, net zoals een div op het web. Je kan Views ook in elkaar nesten om je scherm op te bouwen.

## Line 3 — Echt native (Frame 3)

    Toch is een View geen div. React Native zet hem om naar een echt native element: een U I View op iOS en een Android view op Android. Daarom voelt je app echt native aan.

## Line 4 — Altijd flexbox (Frame 4)

    Een tweede verschil: elke View is standaard een flex container. Display flex hoef je niet te schrijven. De richting is wel column: de kinderen staan onder elkaar, en niet naast elkaar zoals op het web.

## Line 5 — Stylen (Frame 5)

    Met de style prop geef je een View een achtergrondkleur, een rand, padding of een vaste grootte. Hier zet de container zijn inhoud ook in het midden van het scherm.

## Line 6 — Samenvatting (Frame 6)

    Samengevat: de View is de bouwsteen van elk scherm. Hij bevat andere componenten, wordt een native element en is altijd een flex container, met column als richting.
