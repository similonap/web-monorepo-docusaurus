## Line 1 — Hook (Frame 1)

    Wil je tekst tonen in React Native, dan gebruik je de Text component. Hij is te vergelijken met een p of een span op het web.

## Line 2 — Alle tekst in een Text (Frame 2)

    Alle tekst moet in een Text staan. Zet je tekst rechtstreeks in een View, dan krijg je een foutmelding: text strings must be rendered within a Text component.

## Line 3 — Tekststijlen (Frame 3)

    Met style kies je de font size, de font weight en de kleur van je tekst. Text align zet de tekst links, in het midden of rechts.

## Line 4 — Text nesten (Frame 4)

    Je kan een Text ook in een andere Text nesten. De binnenste neemt de stijl van de buitenste over, en kan die aanvullen of overschrijven.

## Line 5 — Geen overerving (Frame 5)

    Maar let op: anders dan in CSS erft een Text niets van een View. Een View heeft zelfs geen color. Tekststijlen gaan enkel van een Text naar een geneste Text.

## Line 6 — Samenvatting (Frame 6)

    Kort samengevat: alle tekst in een Text, en de tekststijl zet je op die Text zelf.
