## Line 1 — Hook (Frame 1)

    Een lijst tonen in React Native gaat net zoals in React. Je neemt een array en mapt elk element naar een component.

## Line 2 — Met een for lus (Frame 2)

    Je zou een for lus kunnen gebruiken. Voor elke naam duw je een Text in een array, en die array zet je in de View. Dat werkt, maar zo doen we het niet.

## Line 3 — Met map (Frame 3)

    Korter en duidelijker is map. Elke kleur uit de array wordt een View, met die kleur als achtergrond.

## Line 4 — De key (Frame 4)

    Elk element in een lijst heeft een key nodig, en die key moet uniek zijn. De kleurnamen zijn hier allemaal verschillend, dus die kunnen we gebruiken.

## Line 5 — Naar Text mappen (Frame 5)

    Je moet niet altijd naar Views mappen. Hier wordt elke kleur een Text, met de naam van de kleur erin.

## Line 6 — Letters (Frame 6)

    Met split maak je van een woord een array van letters. De index bepaalt de font size, en letter plus index wordt de key.
