## Line 1 — Hook (Frame 1)

    Voor lange lijsten heeft React Native de Flat List. Die scrolt vanzelf en rendert enkel de items die op het scherm staan.

## Line 2 — data (Frame 2)

    Je geeft de array mee aan de data prop. Hier is dat een lijst van personen, elk met een id, een naam en een leeftijd.

## Line 3 — renderItem (Frame 3)

    Render item is een functie die voor elk item een component teruggeeft. Je krijgt het item mee, en wij tonen er een Person Component mee.

    Met key extractor geef je elk item een unieke key. Hier nemen we de id, omgezet naar een string.

    Ook het kleurenvoorbeeld kan met een Flat List. Data is de array met kleuren, render item maakt een View, en de kleur zelf is de key.
